# Data Cleaning and Visualization

This repository contains multiple data cleaning, exploratory data analysis, and visualization projects using Python. The main objective of this project is to clean raw datasets, analyze patterns, and create meaningful visualizations to support data-driven decision-making.

## Project Overview

In this project, I worked with different datasets such as sales data, housing data, cafe sales data, and other practice datasets. The focus was on handling messy data, preparing it for analysis, and extracting useful insights through visualizations.

## Objectives

* Clean and preprocess raw datasets
* Handle missing values, duplicate records, and inconsistent data formats
* Perform exploratory data analysis using statistical summaries
* Identify trends, patterns, and relationships in the data
* Create visualizations for better understanding of business insights
* Prepare datasets for further analysis or machine learning tasks

## Tools and Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Excel

## Key Steps Performed

1. Loaded datasets using Pandas
2. Checked dataset shape, columns, data types, and missing values
3. Removed duplicate records
4. Handled missing and inconsistent values
5. Cleaned column names and formatted data properly
6. Performed exploratory data analysis
7. Created visualizations using Matplotlib and Seaborn
8. Generated insights from cleaned datasets
